What This Scanner Checks

🔐

Content-Security-Policy

Controls resource loading origins, reducing XSS attack surface.

🔒

Strict-Transport-Security

Forces HTTPS connections, preventing protocol downgrade attacks.

🚫

X-Content-Type-Options

Prevents MIME-sniffing, blocking content-injection via file uploads.

🖼️

X-Frame-Options

Blocks clickjacking by controlling iframe embedding behaviour.

📡

Referrer-Policy

Limits referrer URL leakage to third-party origins.

🌐

CORS Headers

Analyses cross-origin access policies for wildcard and credential risks.
